🎵 Mini Player – Lightweight Web Music Players

A simple and responsive Mini Music Player built using modern web technologies.
This project allows users to play, pause, skip, and control audio tracks with a clean and user-friendly interface.

🚀 Features

▶️ Play / Pause functionality

⏭️ Next & Previous track navigation

🔊 Volume control

📊 Real-time progress bar

⏱️ Track duration display

📱 Responsive UI design

🎨 Clean and minimal interface

🛠️ Technologies Used

HTML5 – Structure

CSS3 – Styling and layout

JavaScript (Vanilla JS) – Logic and functionality

⚙️ How to Run the Project
Method 1: Run Locally

Download or clone the repository:

git clone https://github.com/anirudh1261/mini-player-master

Open the project folder.

Double-click index.html
OR
Right-click → Open with browser.

Method 2: Run Using Live Server (Recommended)

Install VS Code

Install the Live Server Extension

Right-click on index.html

Click "Open with Live Server"

🌟 Key Functionalities Explained
🎵 Audio Control

JavaScript Audio() object is used to manage playback.

Event listeners handle play, pause, and track switching.

📊 Progress Bar

Uses timeupdate event

Updates progress dynamically based on current playback time.

🔄 Dynamic UI Updates

Button icons change based on playback state.

Track information updates when song changes.
